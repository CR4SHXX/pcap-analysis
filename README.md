## 1. Presentation du projet

### 1.1 Contexte

Ce projet est consacre a l'analyse du trafic reseau a partir de fichiers PCAP pour comprendre les communications entre les machines et identifier les activites suspectes ou malveillantes

### 1.2 Objectifs

- Analyser les fichiers PCAP pour comprendre les communications et les protocoles reseau
- Identifier les anomalies et les patterns d'activites malveillantes
- Investiguer les flux et les paquets pour verifier les comportements suspects
- Reconstituer les sequences d'activites et identifier les indicateurs de compromission (IOC)
- Utiliser Wireshark, tshark et Zeek pour l'analyse et l'investigation
- Associer les comportements identifies aux techniques MITRE ATT&CK
- Documenter les investigations avec les preuves, les resultats et les conclusions
